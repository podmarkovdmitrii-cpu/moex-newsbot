# Новостной бот MOEX (версия 2)

Бот каждые 5 минут в торговые часы читает 33 открытых Telegram-канала (Банк России, Минфин, Правительство, Интерфакс, ПРАЙМ, ТАСС, РБК, MarketTwits и др.), сверяет новости между источниками и присылает в Telegram:

- ⚡️ ранние (неподтверждённые) новости по бумагам — со ссылкой и статистикой источника;
- ✔️ подтверждения, 📰 важные и 🏛 официальные новости — с исторической реакцией цены;
- 🟢/🔴 сделки виртуального счёта 100 000 ₽ по стратегии «Режимная: импульс + откат + шорт пробоя + новости (v2)» — с риском сделки и новостями, на которых принято решение.

Код: папка [`newsbot`](newsbot), расписание: [`.github/workflows/news-bot.yml`](.github/workflows/news-bot.yml).
Подробная инструкция: [Инструкция_GitHub_новостной_бот.pdf](Инструкция_GitHub_новостной_бот.pdf) и [`newsbot/ИНСТРУКЦИЯ-GITHUB.txt`](newsbot/ИНСТРУКЦИЯ-GITHUB.txt).

Для работы нужны секреты репозитория `TG_TOKEN` и `TG_CHAT_ID` (Settings → Secrets and variables → Actions). Необязательно: `TG_NEWS_CHAT_ID` — отдельный чат или канал для новостей.

Бот использует только публичные источники. Виртуальный счёт; не является инвестиционной рекомендацией.
